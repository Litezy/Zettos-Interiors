# MASTER PROJECT PROMPT: ZETTOS INTERIOR UNITS — BRAND, WEBSITE & FULL-STACK APPLICATION

## YOUR ROLE

Act as a senior product designer, brand strategist, UI/UX architect, creative director, frontend engineer and backend engineer with over 10 years of experience building premium digital experiences for architecture studios, interior design companies, construction businesses and real-estate brands.

You are commissioned to design and develop a complete digital presence for **Zettos Interior Units**, a real interior design, interior decoration and building construction company based in Lagos, Nigeria.

Do not approach this as a generic business website.

Your responsibility is to create a distinctive, visually impressive, premium, colourful, conversion-focused and fully functional digital product that gives Zettos the online presence of an established professional design-and-build company.

You must handle the branding, user experience, frontend, backend, database, admin dashboard, content management, integrations, testing and deployment readiness.

Think independently. Make thoughtful product decisions. Do not wait for me to specify every design detail.

# 8. BACKEND AND DATABASE ARCHITECTURE

Implement a real backend with persistent data storage.

First inspect the existing repository and determine its framework, package manager, architecture and installed dependencies.

Do not unnecessarily replace an existing working stack.

If starting from scratch, use the following recommended architecture:

Frontend:
- Next.js App Router.
- React.
- TypeScript.
- Tailwind CSS.
- shadcn/ui where appropriate.
- Framer Motion or Motion for polished animations.
- Lucide icons.

Backend:
- Next.js server-side functionality and route handlers, or a clearly separated backend service if justified.
- PostgreSQL.
- Prisma ORM.
- Secure authentication.
- Input validation using Zod.

File storage:
- Cloudinary or an S3-compatible storage service.
- Support image uploads and document uploads.
- Store file metadata in the database.

Email:
- Resend or another configurable transactional email provider.

Additional integrations:
- WhatsApp click-to-chat.
- Google Maps.
- Analytics.
- Optional CAPTCHA or equivalent spam protection.

### Suggested database entities

Design an appropriate relational database with models such as:

- AdminUser.
- Role.
- Project.
- ProjectCategory.
- ProjectImage.
- Service.
- ServiceImage.
- Enquiry.
- EnquiryAttachment.
- EnquiryNote.
- Testimonial.
- FAQ.
- SiteSetting.
- ActivityLog.

Define proper relationships, indexes, timestamps, validation and constraints.

Create database migrations and seed scripts.

Use environment variables for secrets and external service credentials.

Create a complete .env.example file.

Never commit secrets, passwords, private API keys or production credentials.

### Backend quality

Implement:

- Server-side validation.
- Error handling.
- Authentication and authorization.
- Upload restrictions.
- Rate limiting.
- Secure database queries.
- Protection against common web vulnerabilities.
- Logging.
- Pagination.
- Search and filtering.
- Consistent API response structures.

Do not use local component state as a substitute for persistent backend functionality.

Every dashboard action should connect to actual backend operations.
